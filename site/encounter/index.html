Final Fantasy VII Encounter Patcher

Replace vanilla field Danger accumulation with an RCnt2 FORCE check. At default Enemy Lure, about 3.1% of encounter checks FORCE a battle roll (50% of the raw lure/256 rate). Enemy Lure / Away still scale; preempt / StepID routing stays intact.

  1. Use a clean NTSC-U (US) Disc 1 .bin (not an already-patched image).
  2. Select the encounter patch from the dropdown.
  3. Click Apply patch — downloads the patched .bin and a matching .cue.
  4. Keep both files in the same folder (allow multiple downloads if asked).

Path: step wrap → RCnt2 vs lure/2 sets Danger to max or zero → vanilla dual StepID rolls → Lure/Away threshold. Prefer the disc builder for CSR stacks.
