# D2/D3 field movies missing on D1 (single-disc trim candidates)

When playing Clean D1-only, Set next movie uses the **D1 movie index table**.
Makou labels like "loslake1 (disc 2)" mean: same PMVIE id number, different file per disc.

This inventory scans **D2 and D3** FIELD scripts for PMVIE+MOVIE pairs whose resolved
filename is **not on D1**. Those scenes are the ones most likely to crawl / blank / wrong
on D1-only if the Play movie is still present in the D1 field DAT.

**Action on D1 work bin:** Makou open the same DAT name, Find Play movie / Set next movie,
delete those ops; keep Wait / Jump / Execute. Confirm in Makou — auto-scan can false-positive.

D2-only MOVIE files: 46 | D3-only: 10
